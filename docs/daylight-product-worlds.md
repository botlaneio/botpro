# Daylight product worlds

Reference lock: Entire's quiet near-white canvas and rich, bounded landscape-backed
product scenes; Botlane's existing grey canvas, Inter type, blue studio accent and
teal/violet/orchid product scopes. Preserve Botlane's header, hero narrative, service
copy and product status. Borrow the contrast between rich artwork and white UI,
not Entire's imagery or layout.

One original generated glacial-inlet illustration is shared across the product
scenes. UI is live React markup; all example records are explicitly illustrative.

fan stays in dark mode. Tabs are manual with keyboard navigation and no autoplay.
Illustrative scan/flow animations respect reduced motion. The shared ambient
page wash is reduced on the homepage in light mode so saturated artwork can carry
colour. Existing Insights daylight-material refinements are included from #109.
